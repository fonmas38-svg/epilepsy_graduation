## ما الذي يجعله مناسباً كمشروع تخرج؟
1. مشكلة طبية حقيقية (التنبؤ المبكر بنوبات الصرع)
2. مسار كامل: جهاز → سيرفر → نموذج AI → تطبيق → تنبيهات
3. أدوار متعددة: مريض / أسرة / طبيب
4. تخزين محلي + إمكانية سحابة
5. توثيق تقني وبروتوكول جهاز رأس

## المكوّنات الحالية (V2)
- Backend FastAPI + نموذج تصنيف خطر
- `/device/ingest` لاستقبال عينات جهاز الرأس

- تطبيق Flutter مع تبويب ربط الجهاز
- شاشات الأدوار الثلاثة + تقارير الطبيب

## خطة المناقشة أمام اللجنة
1. عرض المشكلة من ملف الرؤية
2. المعمارية (جهاز/سيرفر/موبايل)
3. تجربة محاكاة ثم تجربة إرسال من محاكي الجهاز
4. إظهار التنبيه عند high_risk
5. توضيح حدود النظام (تعليمي، يحتاج بيانات سريرية لاحقاً)
