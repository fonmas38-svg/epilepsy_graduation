# MVP بدون جهاز — ما تم تجهيزه

## الهدف
إكمال مرحلة مشروع التخرج الأساسية دون انتظار الهاردوير.

## ما يعمل الآن
1. Dataset إشارات EEG/ECG/Motion موسوم (`stable` / `watch` / `high_risk`)
2. تدريب نموذج حقيقي من الـ Dataset ومقارنته بين خوارزميات
3. مصدر بيانات في التطبيق: **Dataset** (موصى به) / محاكاة / جهاز لاحقاً
4. تخزين سحابي مبسط على السيرفر (`/cloud/...`) يشارك القراءات والتنبيهات
5. تنبيه `high_risk` يصل منطقياً لـ المريض + الأسرة + الطبيب (عبر السحابة المحلية للسيرفر)
6. `watch` يمثل مرحلة ما قبل الخطر المرتفع (تمهيد للـ Prediction)

## التشغيل
```bash
cd backend
python data/build_dataset.py
python train_from_dataset.py
uvicorn app.main:app --host 0.0.0.0 --port 8000

cd ../mobile
flutter run
```
في التطبيق: مريض → تبويب الجهاز → **تشغيل من Dataset**

الأسرة/الطبيب: زر تحديث السحابة لسحب آخر التنبيهات.
