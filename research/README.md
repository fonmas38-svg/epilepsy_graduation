# البحث والتقييم

هذا المجلد يحتوي تجارب تدريب، وليس نموذجًا مثبت الصلاحية الطبية. لا توجد نسبة دقة مضمونة أو دليل محلي مستقل على التنبؤ قبل النوبة بـ15–30 دقيقة.

## مسارات البيانات

- `colab_seizure_detection.ipynb`: الدفتر الموجود في المشروع. A هي مقاطع Bonn لمهمة الكشف داخل النافذة؛ B موجات صناعية مولدة، وليست CHB-MIT. مجموعات Bonn هي تسجيلات، وليست هويات مرضى مؤكدة. النموذج السحابي في هذا الدفتر يتدرب على مزيج A وB، فلا يصح تفسير أدائه كدقة تنبؤ سريرية.
- `build_notebook.py`: مولد الدفتر؛ أُصلح مصدره والدفتر الناتج معًا. اختيار عتبة الدمج يتم على التحقق فقط. لا يعيد توليد الدفتر تدريب الأوزان.
- `train_seizure_cloud.py`: تجربة مستقلة تستخدم أيضًا مولد بيانات صناعية. لا تستبدل تقييم EEG متصل.
- `scripts/edf_prep.py` و`scripts/train.py`: مسار منفصل لبيانات EDF المعلمة عند توفرها. المعالجة الحالية غير سببية على مستوى التسجيل وليست تقييمًا حيًا مستقبليًا. يفشل المسار عند غياب معلومات أساسية أو اختلاف المونتاج بدل قص القنوات ضمنيًا.

## ما يعمل في التطبيق

الخادم يستطيع تشغيل الأوزان عند توافق المدخلات؛ هذا يثبت التنفيذ فقط. خدمة الهاتف الحالية قواعد إشارة تجريبية، ولا تنفذ ملف ONNX. صيغة الدمج في الدفتر تجربة بحثية ولا تطابق تلقائيًا دمج EEG والسياق الحيوي في الخادم.

## الأدوات القابلة لإعادة التشغيل

```bash
python research/build_notebook.py
python research/scripts/audit_artifacts.py
python research/scripts/evaluate_holdout.py --help
```

الدفتر المصحح يصدر الأوزان وبصماتها وملفي `edge_holdout.npz` و`cloud_synthetic_holdout.npz`. الملف الثاني صناعي ولا يستخدم لإثبات تنبؤ لدى المرضى. لا توجد حاجة لنقل كامل EEG لمراجعة هذه المخرجات الأولى.
